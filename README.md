# jhleao/homebrew-tap

Homebrew formulas and casks maintained by [José Leão](https://github.com/jhleao).

You can install a package directly without adding the tap first:

```sh
brew install jhleao/tap/<package>
```

Or add the tap once, then use package names normally:

```sh
brew tap jhleao/tap
brew install <package>
```

## Packages

| Package | Description | Install |
| --- | --- | --- |
| [Stamp](https://github.com/jhleao/stamp) | Collaborative documents from Markdown, TSX, and Tailwind | `brew install jhleao/tap/stamp` |

Formula updates may be automated by their upstream release workflows. Please
report package-specific problems in the linked upstream repository.
